# Agentic Design Patterns

Каталог паттернов агентного программирования в духе «Банды четырёх». Паттерны описывают повторяющиеся задачи при работе с ИИ-агентом и способы их решения. По ним можно выбрать подход к постановке задачи, подготовке контекста, проверке результата и организации проекта. В разделе об **анти-паттернах** разобраны типовые ошибки взаимодействия с агентом.

Паттерны сгруппированы по областям работы. [Оглавление](SUMMARY.md) задаёт порядок глав и служит навигацией книги.

Начните с [предисловия](preface.md) и главы [«Как читать книгу»](how-to-read.md).
