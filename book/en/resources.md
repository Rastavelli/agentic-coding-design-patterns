## Other SDD tools

Not covered by their own articles, but mentioned in the text and in the
comparison:

- **GitHub Spec Kit** — the canonical toolkit with a command per phase:
  [speckit.org](https://speckit.org/) ·
  [github.com/github/spec-kit](https://github.com/github/spec-kit)
- **Kiro** — SDD as an IDE mode from AWS: [kiro.dev](https://kiro.dev/)
- **Tessl** — the specification as the source of code:
  [tessl.io](https://tessl.io/)
- **BMAD-Method** — SDD in an agile wrapper with role agents:
  [github.com/bmad-code-org/BMAD-METHOD](https://github.com/bmad-code-org/BMAD-METHOD)
- **Spec Kitty** — a Spec Kit fork with built-in git worktrees:
  [github.com/Priivacy-ai/spec-kitty](https://github.com/Priivacy-ai/spec-kitty)
- **Traycer** — a Plan → Execute → Verify layer for VS Code:
  [traycer.ai](https://traycer.ai/)
