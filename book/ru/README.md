# Agentic Design Patterns

Каталог паттернов агентного программирования в духе «Банды четырёх». Паттерны описывают повторяющиеся задачи при работе с ИИ-агентом и способы их решения. По ним можно выбрать подход к постановке задачи, подготовке контекста, проверке результата и организации проекта. В разделе об **антипаттернах** разобраны типовые ошибки взаимодействия с агентом.

Паттерны сгруппированы по областям работы. [Оглавление](SUMMARY.md) задаёт порядок глав и служит навигацией книги.

Начните с [предисловия](preface.md) и главы [«Как читать книгу»](how-to-read.md).

Книгу создал [Кирилл Мокевнин](https://github.com/mokevnin) при поддержке [Хекслета](https://hexlet.io) и [Праксора](https://praxor.ru/).

[Хекслет](https://hexlet.io) — онлайн-школа программирования. Обучение строится вокруг практики: студенты решают задачи, создают проекты и получают обратную связь от наставников. Курсы помогают освоить основы разработки и развивать инженерные навыки.

[Праксор](https://praxor.ru/) помогает инженерным командам внедрять ИИ-агентов во весь цикл разработки — от постановки задачи до выпуска изменений. Команда настраивает рабочие процессы, контекст для агентов и проверки качества на реальной кодовой базе, а результат оценивает по влиянию на скорость и качество разработки.
