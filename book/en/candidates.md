# Candidates and voting

Which topics should the book cover next? These are short proposals for new chapters. They are not accepted yet, and some may merge into existing patterns. The last two topics are proposed anti-patterns.

The full list, sources, overlaps, and current statuses are in [CANDIDATES.md](https://github.com/mokevnin/agentic-coding-design-patterns/blob/main/CANDIDATES.md).

## How to vote

Open “Discuss / vote” next to a topic. Find the issue with its identifier and add a 👍 reaction to the opening post. You can support several topics. Comments describing a task where you need the pattern are especially useful.

If there is no discussion yet, [create an issue using the template](https://github.com/mokevnin/agentic-coding-design-patterns/issues/new?template=pattern-candidate.md&title=%5BCandidate%5D+%3Cslug%3E). Replace `<slug>` in the title with the identifier from the table and describe your use case. Russian, English, and Spanish are welcome; participation requires a GitHub account.

Before creating an issue, check the results, including closed discussions: a topic may already have a chapter or have been merged with another. Votes indicate reader interest; inclusion remains an editorial decision.
