# Enlaces útiles

Una colección de enlaces a herramientas de
[desarrollo orientado a especificaciones](spec-driven-development.md) y a una
comparación externa que ayuda a elegir la adecuada.

## Herramientas analizadas en el libro

- **[OpenSpec](openspec.md)** — [openspec.dev](https://openspec.dev/) ·
  [github.com/Fission-AI/OpenSpec](https://github.com/Fission-AI/OpenSpec)
- **[Superpowers](superpowers.md)** —
  [github.com/obra/superpowers](https://github.com/obra/superpowers)
- **[Skills de Matt Pocock](matt-pocock-skills.md)** —
  [github.com/mattpocock/skills](https://github.com/mattpocock/skills)

## Otras herramientas de SDD

No analizadas en artículos propios, pero mencionadas en el texto y en la
comparación:

- **GitHub Spec Kit** — el toolkit canónico con un comando por fase:
  [speckit.org](https://speckit.org/) ·
  [github.com/github/spec-kit](https://github.com/github/spec-kit)
- **Kiro** — SDD como modo del IDE de AWS: [kiro.dev](https://kiro.dev/)
- **Tessl** — la especificación como fuente del código:
  [tessl.io](https://tessl.io/)
- **BMAD-Method** — SDD con envoltorio agile y agentes de rol:
  [github.com/bmad-code-org/BMAD-METHOD](https://github.com/bmad-code-org/BMAD-METHOD)
- **Spec Kitty** — un fork de Spec Kit con git worktrees integrados:
  [github.com/Priivacy-ai/spec-kitty](https://github.com/Priivacy-ai/spec-kitty)
- **Traycer** — una capa Plan → Execute → Verify para VS Code:
  [traycer.ai](https://traycer.ai/)
